API Reference

RESTful API documentation for CyberSec Pro. Automate your security workflow.

Authentication

All API requests require a Bearer token. Get your token from the dashboard settings.

# Example request
curl -H "Authorization: Bearer YOUR_TOKEN" \
  https://semihkilic.com/api/v1/scans

Scans

GET/api/v1/scansList all scans
POST/api/v1/scansCreate new scan
GET/api/v1/scans/:idGet scan details
GET/api/v1/scans/:id/resultsGet scan results
DELETE/api/v1/scans/:idDelete scan

Tools

GET/api/v1/toolsList all 401 tools
GET/api/v1/tools/:idGet tool details
GET/api/v1/tools/categoriesList categories

Reports

GET/api/v1/reportsList reports
POST/api/v1/reports/generateGenerate report (HTML/PDF/JSON/CSV/MD)
GET/api/v1/reports/:id/downloadDownload report

Vulnerabilities

GET/api/v1/vulnerabilitiesList vulnerabilities
PUT/api/v1/vulnerabilities/:idUpdate vulnerability status

Organization

GET/api/v1/organizationGet org details
GET/api/v1/organization/membersList members

Rate Limits

  • Starter: 100 requests/minute
  • Professional: 500 requests/minute
  • Enterprise: 2,000 requests/minute
