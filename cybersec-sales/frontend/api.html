📡 REST API

API Documentation

Integrate 401 Kali Linux security tools into your applications with our powerful REST API.

Base URL: https://semihkilic.com/api/v1

🔐 Authentication

All API requests require authentication using an API key. Include your key in the request header: 

Authorization: Bearer YOUR_API_KEY

# Example with cURL
curl -H "Authorization: Bearer sk_live_abc123..." \
     https://semihkilic.com/api/v1/tools

Get Your API Key

  1. Login to your dashboard
  2. Navigate to Settings → API Keys
  3. Click "Generate New Key"
  4. Copy and store your key securely

📋 Endpoints

Tools

GET /tools

List all available security tools with categories.

// Response
{
  "tools": [
    {
      "id": "nmap",
      "name": "Nmap",
      "category": "information-gathering",
      "description": "Network discovery and security auditing"
    }
  ],
  "total": 401
}
POST /tools/{tool_id}/run

Execute a security tool with specified parameters.

// Request Body
{
  "args": ["-sV", "-p", "1-1000"],
  "target": "scanme.nmap.org",
  "timeout": 300
}
// Response
{
  "job_id": "job_abc123",
  "status": "running",
  "started_at": "2026-01-23T10:00:00Z"
}

Jobs

GET /jobs/{job_id}

Get the status and results of a job.

// Response
{
  "job_id": "job_abc123",
  "status": "completed",
  "output": "Starting Nmap scan...",
  "exit_code": 0,
  "completed_at": "2026-01-23T10:02:30Z"
}

Quick Scans

POST /scan/url

Perform a quick security scan on a URL.

// Request
{ "url": "https://example.com" }

// Response
{
  "url": "https://example.com",
  "security_headers": { ... },
  "ssl_info": { ... },
  "risk_score": 85
}
GET /scan/mx/{domain}

Lookup MX records and email security for a domain.

// Response
{
  "domain": "example.com",
  "mx_records": ["mail.example.com"],
  "spf": true,
  "dkim": true,
  "dmarc": true
}

Projects

GET /projects

List all projects in your workspace.

POST /projects

Create a new project.

DELETE /projects/{project_id}

Delete a project and all associated data.
