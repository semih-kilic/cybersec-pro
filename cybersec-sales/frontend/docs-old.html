Installation Guide

Get CyberSec Pro up and running in minutes with our simple installation process.

⚡ Quick Start

Install CyberSec Pro with a single command:

curl -sSL https://semihkilic.com/install.sh | bash

After installation, start the application:

cybersec start

Then open http://localhost:5173 in your browser.

📋 System Requirements

Minimum

  • ✓ Linux (Ubuntu 20.04+, Debian 11+, Kali)
  • ✓ Python 3.8+
  • ✓ 4 GB RAM
  • ✓ 10 GB Disk Space

Recommended

  • ★ Kali Linux (latest)
  • ★ Python 3.10+
  • ★ 8 GB RAM
  • ★ SSD Storage
💡

Kali Linux Recommended

Kali Linux comes with most security tools pre-installed. On other distributions, some tools may need manual installation.

📦 Installation Methods

Recommended

Automatic Installation

The installer automatically detects your OS, installs dependencies, and sets up everything:

# Standard installation
curl -sSL https://semihkilic.com/install.sh | bash

# With additional security tools
curl -sSL https://semihkilic.com/install.sh | bash -s -- --with-tools

Manual Installation

Step 1: Download and extract

wget https://semihkilic.com/downloads/cybersec-pro-linux.tar.gz
tar -xzf cybersec-pro-linux.tar.gz
cd cybersec-pro

Step 2: Setup Python environment

python3 -m venv backend/venv
source backend/venv/bin/activate
pip install -r backend/requirements.txt

Step 3: Start the application

./start.sh

🐳 Docker Installation

Run CyberSec Pro in an isolated Docker container:

# Quick Docker install
curl -sSL https://semihkilic.com/install.sh | bash -s -- --docker

Or manually with docker-compose:

# Download docker-compose.yml
curl -O https://semihkilic.com/downloads/docker-compose.yml

# Start the container
docker-compose up -d

# Access the dashboard
open http://localhost:5173

💻 CLI Commands

Command Description
cybersec start Start CyberSec Pro
cybersec stop Stop CyberSec Pro
cybersec restart Restart CyberSec Pro
cybersec status Check if running
cybersec open Open dashboard in browser
cybersec update Update to latest version
cybersec logs View application logs
cybersec help Show all commands

🔧 Troubleshooting

Port already in use

If port 5173 or 5001 is already in use:

# Kill existing processes
pkill -f "python.*app.py"
pkill -f "node.*5173"

# Or find and kill specific port
lsof -i :5173
kill -9 <PID>
Permission denied

Make scripts executable:

chmod +x start.sh stop.sh install.sh
Python not found

Install Python 3:

# Ubuntu/Debian/Kali
sudo apt install python3 python3-pip python3-venv

# Fedora
sudo dnf install python3 python3-pip

# Arch
sudo pacman -S python python-pip
Module not found errors

Reinstall Python dependencies:

cd ~/cybersec-pro
source backend/venv/bin/activate
pip install --upgrade -r backend/requirements.txt
