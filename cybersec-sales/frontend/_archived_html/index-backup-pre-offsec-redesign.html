Frequently Asked Questions

What is CyberSec Pro? +

CyberSec Pro is a cloud-based penetration testing platform powered by 396 Kali Linux security tools. It enables organizations to run enterprise-grade vulnerability scans directly from their browser — no VMs, no infrastructure, no setup required.

How does it compare to manual penetration testing? +

Manual pentesting typically costs $5,000–$20,000 per engagement and happens 1–2 times per year. CyberSec Pro provides continuous daily scanning across all 396 tools starting at €99/month — 85% more cost-effective with 365x more frequent coverage.

Which compliance frameworks do you support? +

CyberSec Pro generates compliance-ready reports for SOC 2 Type II, ISO 27001, GDPR, HIPAA, PCI DSS, and NIST CSF. Our reports map findings directly to control requirements, making audit preparation significantly faster.

Can I integrate CyberSec Pro into my CI/CD pipeline? +

Yes. Professional and Enterprise plans include full REST API access. Integrate with GitHub Actions, Jenkins, GitLab CI, CircleCI, or any pipeline. Fail builds automatically when critical vulnerabilities are detected.

Where is my data stored? +

All scan data is encrypted at rest (AES-256) and in transit (TLS 1.3). Data is stored in SOC 2-compliant infrastructure. European customers can opt for EU-only data residency. We never share scan results with third parties.

Is this legal? Do I need authorization? +

CyberSec Pro is designed for authorized security testing only. You must own or have written permission to scan any target. Our platform includes built-in authorization verification and scope controls to ensure responsible use.
