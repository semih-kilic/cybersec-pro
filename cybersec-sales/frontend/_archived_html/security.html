Security

How CyberSec Pro protects your data and infrastructure.

🔒

Encryption at Rest

All data encrypted with AES-256. Database fields containing sensitive scan results use additional application-level encryption.

🔐

Encryption in Transit

TLS 1.3 enforced on all connections. HSTS enabled with 1-year max-age. Certificate pinning for API clients.

🛡

Authentication

JWT with short-lived tokens. TOTP-based MFA support. GitHub OAuth integration. Bcrypt password hashing with work factor 12.

⚙

Infrastructure

Isolated scan environments. Network segmentation. Regular security patches. Automated vulnerability scanning of our own infrastructure.

📋

Compliance

SOC 2 Type II compliant. GDPR compliant with EU data residency. Regular third-party penetration tests.

🔍

Monitoring

24/7 security monitoring. Anomaly detection on all API endpoints. Comprehensive audit logging with tamper-proof storage.

Vulnerability Disclosure

We welcome responsible security researchers. If you discover a vulnerability in our platform, please report it to cybersecpro@semihkilic.com.

Bug Bounty: We offer rewards for qualifying vulnerability reports. Severity-based payouts from €100-€5,000. See our responsible disclosure policy for details.

Incident Response

Our incident response team operates 24/7. In case of a security incident, affected users are notified within 72 hours per GDPR requirements. Post-incident reports are published transparently.
