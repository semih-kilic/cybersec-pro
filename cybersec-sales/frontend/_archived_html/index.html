Frequently asked

What is CyberSec Pro?

A cloud-based offensive security platform providing browser access to 396 Kali Linux tools across 61 categories. Run penetration tests, vulnerability scans, and red team engagements without installing anything locally.

What's included in the free trial?

14 days of platform access with 50 security tools. Run one full engagement and generate a detailed PDF report. No credit card required. Upgrade anytime for the full arsenal.

How are tools distributed across tiers?

Recon (Free): 50 tools. Operator: 100 tools. Red Team: 250 tools. APT: all 396 tools. Higher tiers unlock more advanced exploitation and post-exploitation capabilities.

Is penetration testing legal?

Yes — when performed on systems you own or have explicit written authorization to test. CyberSec Pro is designed for authorized security assessments only. Always get written permission first.

Can I cancel anytime?

Yes. All plans are month-to-month. Cancel through dashboard settings. Access continues until end of billing period. No exit fees.

Which compliance frameworks are supported?

Red Team and APT plans include automated report generation mapped to NIST, OWASP, GDPR, PCI DSS, HIPAA, and SOC 2. See our documentation for mapping details.
