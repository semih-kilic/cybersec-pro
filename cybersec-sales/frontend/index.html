FAQ

Questions & answers

What exactly is CyberSec Pro?

CyberSec Pro is a cloud-based platform that provides browser access to 401 Kali Linux security tools across 61 categories. Run penetration tests, vulnerability scans, and security assessments without installing anything locally.

What does the free trial include?

14 days of platform access with 50 security tools. Run one comprehensive scan and generate a detailed PDF report. No credit card required. Upgrade anytime for more tools.

How are tools distributed across plans?

Free Trial: 50 tools. Starter: 100 tools. Professional: 250 tools. Enterprise: all 401 tools. Higher tiers include more advanced and specialized security tools.

Is penetration testing legal?

Yes, when performed on systems you own or have explicit written authorization to test. CyberSec Pro is intended for authorized security testing only.

Can I cancel my subscription?

Yes. All plans are month-to-month. Cancel anytime through your dashboard settings. You keep access until the end of your billing period.

Which compliance frameworks are supported?

Professional and Enterprise plans include report generation mapped to NIST, OWASP, GDPR, PCI DSS, HIPAA, and SOC 2 frameworks. See our documentation for details.
