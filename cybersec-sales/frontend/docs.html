🚀 Getting Started

CyberSec Pro is a cloud-based platform that gives you access to 682 Kali Linux security tools directly from your browser. No installation, no configuration—just sign in and start testing.

Step 1: Create Account

  1. Go to semihkilic.com/login
  2. Click "Start Free Trial"
  3. Enter your email and create a password
  4. Verify your email address

Step 2: Access Dashboard

After registration, you'll be redirected to your dashboard at semihkilic.com/app

Step 3: Start Using Tools

Browse tools by category, select one, and run it against your target. Results appear in real-time in the terminal.

🛠️ Using Tools

Running a Scan

# Example: Nmap port scan
$ nmap -sV -p 1-1000 scanme.nmap.org

# Example: Directory brute force
$ gobuster dir -u https://target.com -w /usr/share/wordlists/common.txt

# Example: SQL injection test
$ sqlmap -u "https://target.com/page?id=1" --dbs

❓ FAQ

Do I need to install anything?

No! CyberSec Pro runs entirely in the cloud. Just open your browser and start using tools.

Is my data secure?

Yes. All data is encrypted in transit and at rest. Each user session runs in an isolated container. See our Security page for details.

Can I use this for illegal hacking?

Absolutely not. CyberSec Pro is for authorized security testing only. You must have permission to test any target. Violations result in immediate account termination.

How do I cancel my subscription?

Go to Settings → Billing → Cancel Subscription. You'll retain access until the end of your billing period.
