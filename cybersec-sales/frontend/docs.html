Getting Started

1. Create Your Account

Register at semihkilic.com/dashboard/login. You can sign up with email or GitHub OAuth.

2. Set Up MFA

Enable multi-factor authentication from Settings → Security. We support TOTP apps like Google Authenticator and Authy.

3. Run Your First Scan

Navigate to Scans → New Scan. Enter your target URL or IP, select tools, and click Start Scan.

Important: Only scan targets you own or have explicit written permission to test.
